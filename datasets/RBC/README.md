# Synthetic RBC

Generated by common/object_models.py using Evans–Fung / Dao geometry, 0.35 µm sampling and literature Hb contrast. Five models: normal, variable, tilt, double, triple. Independent geometry seed and noise seed. Triple field includes 50 groups of 100 cells; group 31 is a deliberately hard geometry, not an inverse input. Synthetic phase-screen, not measured QPI or multiple scattering.
