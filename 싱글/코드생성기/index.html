이 HTML은 명령어 생성기다. 실제 Python 계산은 실행하지 않는다. 최신 개발 브랜치의 CLI가 설치된 폴더에서 사용해야 한다.
일반 이미지 미리보기는 저장소 입력 이미지에서 가져오며, RBC는 기본 합성 위상맵이다. 새 벤치마크는 로컬 실행 시 저장소 파일, 온라인 실행 시 동일 저장소의 고정 커밋 PNG를 읽는다. 실제 복원 결과가 아니다. Blind와 새 통합 복원기의 전체 성능은 별도 검증이 필요하다.
